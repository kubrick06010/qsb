# Security Policy

## Supported Versions

QSB is in early development. Security fixes are applied to the `main` branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting or contact the repository
maintainers through a private GitHub channel. Include:

- a short description of the issue;
- affected commands, files, or workflows;
- steps to reproduce with redistributable inputs;
- the expected impact;
- any suggested fix, if known.

Maintainers will acknowledge reports as soon as practical, investigate, and
coordinate a fix before public disclosure when appropriate.
