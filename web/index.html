CLI Workflow Examples
# Solve a legacy model with native deterministic engine swift run qsb solve model.lp_ --backend native # Validate model semantics and bounds swift run qsb validate model.lp_ # Export clean normalized JSON swift run qsb export-json model.lp_ > model.json # Solve normalized JSON directly swift run qsb solve-json model.json

Engineering Foundation

Clean-Room Architecture

Designed according to strict clean-room principles to guarantee portability, stability, and longevity.

1

QSBCore Domain Engine

Pure Swift package independent of SwiftUI, AppKit, or CLI arguments. Houses model schemas, normalization, parsers, and deterministic algorithms.

2

macOS Native App

Thin client built purely with SwiftUI and AppKit. Strictly observes model state without duplicating solvers or validation math.

3

Portable CLI (`qsb`)

Lightweight executable handling exit codes, standard I/O streaming, batch validation, and automated continuous integration testing.
